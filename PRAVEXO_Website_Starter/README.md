# PRAVEXO Website Starter

This is a responsive, one-page B2B website starter for PRAVEXO — AI & Business Systems / People • Process • Growth.

## Before publishing (mandatory)
1. Replace `91XXXXXXXXXX` in `index.html` with the official WhatsApp number in international digits-only format (example: `919876543210`). The enquiry form will not open WhatsApp while the placeholder remains.
2. Confirm the final Instagram username and add its URL to the nav/footer if desired.
3. Add the official business email and domain once secured. Update the SEO title/description and Open Graph metadata if the positioning changes.
4. Confirm all service claims, industries and scope match what PRAVEXO can reliably deliver today.
5. Connect analytics and a privacy notice before running paid ads or collecting prospect data at scale.
6. Test the site on Android, iPhone, desktop and a slow connection. Test all links and form behavior before sharing publicly.

## Preview locally
Open `index.html` in a modern browser. The website is plain HTML/CSS/JavaScript and has no package install requirement.

## Hosting choices
- For a visual/no-code edit-and-publish workflow, recreate the design in Framer or another managed builder and connect a custom domain.
- For this exact static site, publish the folder on a static host such as Netlify, Vercel or Cloudflare Pages. Upload the folder contents, not the ZIP as a public file.

## Content principles
- Prioritise original video and clear local context over reposted trend content.
- Every Reel needs one idea, a useful opening line, readable on-screen text, a clear payoff and one CTA.
- Use local place tags only when genuinely relevant; do not keyword-stuff captions.
- Do not claim client outcomes, revenue lift, leads or ROI unless measured and approved by the client.
- Track shares/sends per reach, average watch time or retention where available, profile visits, saves, qualified DMs and calls booked—not views alone.
